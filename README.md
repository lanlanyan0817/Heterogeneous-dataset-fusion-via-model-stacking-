# Bridging Models and Modalities: Fusing Models Created from Diverse Multimodal Datasets

Code and reproduction workflow for the accompanying transport choice-model fusion study. The repository combines predictive distributions from a Street (online) MCPT model and a Lab eye-tracking (ET) MCPT model using PSIS-LOO stacking, pseudo-BMA, and BB-pseudo-BMA. It also contains maximum-likelihood (MLE) baselines and supplementary analyses.

## Repository layout

- `data/` — input datasets (`online data.csv`, `lab data.csv`); place the files here before running the workflow.
- `src/mcpt_core.py` — shared MCPT preprocessing and prediction functions.
- `scripts/` — numbered main reproduction steps and optional verification scripts.
- `analysis/` — additional analyses for Sections 4.3–4.5 and Appendix C.
- `estimation/` — Stan model source files generated by estimation scripts.
- `posterior/` — fitted Bayesian posterior NetCDF files.
- `splits/` — generated split manifests and summaries.
- `results/` — generated model, table, figure, and diagnostic outputs.
- `diagnostics/historical_notes/` — historical development notes (not required for the main workflow).


## Dataset

This study uses two stated-choice datasets from the original research project, available at [jiaxuan-ding/uncertainty](https://github.com/jiaxuan-ding/uncertainty), associated with the study Preferences for Electric Vehicles under Uncertain Charging Prices: An Eye-tracking Study.

Both datasets investigate choices involving conventional vehicles (CV), electric vehicles (EV), and an outside option (OC), but were collected under different experimental settings:

- **Street dataset (`online data.csv`):** Contains stated-choice observations collected through a street-intercept experiment, without eye-tracking measurements.
- **Lab dataset (`lab data.csv`):** Contains stated-choice observations collected in a laboratory experiment, together with eye-tracking measurements used to characterize attention to choice attributes.

The online dataset contains 152 participants, each completing two choice tasks, while the lab dataset contains 40 participants, each completing five choice tasks.

**Data availability:** The raw datasets are not redistributed in this repository. To reproduce the analyses, download online data.csv and lab data.csv from the original repository and place them in the data/ directory.

## Requirements

The analyses were conducted on macOS (Apple Silicon) using Python and Stan. The currently recorded environment includes:

- Python 3.10.19
- CmdStanPy 1.3.0
- CmdStan 2.38

The main Python dependencies are listed in `requirements.txt`.

To create a new environment and install the required packages:

```bash
conda create -n model_stacking python=3.10.19
conda activate model_stacking
python -m pip install -r requirements.txt
```

To install CmdStan 2.38:

```bash
python -c "from cmdstanpy import install_cmdstan; install_cmdstan(version='2.38.0')"
```

Running the Stan estimation scripts requires a working C++ compiler.

## Reproduce main results

Run the following scripts in order:

```bash
python scripts/01_data_observe.py
python scripts/02_data_split.py
python scripts/03_web_mcpt_stan.py
python scripts/04_lab_ET_mcpt_stan.py
python scripts/05_posterior_diagnostics.py
python scripts/06_predictive_densities.py
python scripts/07_model_fusion.py
python scripts/08_baseline_models.py
python scripts/09_final_results.py
```

| Step | Purpose |
| --- | --- |
| 01 | Inspect datasets and summarize eye-tracking attention. |
| 02 | Reconstruct participant-level train/test splits and save split information. |
| 03 | Estimate the Bayesian Street/Web MCPT model. |
| 04 | Estimate the Bayesian Lab-ET MCPT model. |
| 05 | Summarize posterior convergence diagnostics (R-hat, ESS, divergences) and parameters. |
| 06 | Compute pointwise predictive densities for the target domains. |
| 07 | Estimate fusion weights and evaluate stacking, pseudo-BMA, and BB-pseudo-BMA. |
| 08 | Re-estimate the MLE baseline models for both target domains. |
| 09 | Produce Tables 2–3 and Figures 5–6 from saved Step 07/08 results. |

**Target domains:** Domain 1 evaluates the street/online target domain; Domain 2 evaluates a pooled street-and-lab target domain. Train/test splitting is at the participant level. The analysis uses ten split seeds: `12, 22, 32, 42, 52, 62, 72, 82, 92, 102`.

Step 09 writes `table_2_domain1.csv/.tex`, `table_3_domain2.csv/.tex`, and the corresponding performance comparison figures (PNG/PDF) under `results/final/`. Step 05 writes `results/posterior_diagnostics.csv` and `results/posterior_parameter_summary.csv`. Fusion and baseline summaries are saved under `results/model_fusion/` and `results/baselines/`, respectively.

## Additional paper analyses

After the required upstream outputs are available, run the relevant analysis scripts:

```bash
# Section 4.3 — Table 4, Figures 7–8 (illustrative seed)
python analysis/section_4_3_stacking_gains.py --seed 42

# Section 4.4 — composition sensitivity, Table 5 and Figure 9
python analysis/section_4_4_composition_sensitivity.py

# Section 4.5 — attention/covariate correlations
python analysis/section_4_5_attention_correlations.py

# Section 4.5 — prepare observation-to-participant mapping, then Table 6
python analysis/prepare_logit_task_ids.py
python analysis/section_4_5_logit_stacking.py

# Appendix C — attention-transfer sensitivity, Table 10
python analysis/appendix_c_attention_transfer_sensitivity.py
```

`prepare_logit_task_ids.py` must run before `section_4_5_logit_stacking.py`: it reconstructs 40 task-ID manifests under `results/logit_stacking/` from the Step 06 ordering and source data. These manifests are **not** independent task identifiers stored inside the predictive-density NPZ files. The Section 4.3 script defaults to seed 42 for its illustrative figures.

Additional outputs are saved in subdirectories of `results/analysis/`.

## Optional verification

```bash
python scripts/verify_data_and_inputs.py
python scripts/verify_prediction_alignment.py
```

The first script checks split and training-input consistency without Stan sampling. The second checks prediction alignment and consistency of saved posterior observed choices and generated quantities. These checks support, but do not establish, the historical identity of every task row when different tasks share the same observed choice.

## Reproducibility notes

- The scripts retain the study's existing preprocessing, model specifications, and split conventions; changes to data ordering or parameterization can change the results.
- Estimation scripts may regenerate Stan source files; keep copies of outputs if you need to compare runs.
- Passing verification checks does not by itself prove that every historical artifact is reproduced bit-for-bit.
- For an exact end-to-end reproduction, record Python/package versions, Stan toolchain versions, input data provenance, and the manuscript version used for comparison.
